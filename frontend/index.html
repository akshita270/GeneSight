BRCA1 → Breast Cancer
BRCA1 normally repairs broken DNA. A mutation breaks this repair system — cells divide uncontrollably, causing tumors.
APOE4 → Alzheimer's
APOE4 affects how the brain clears protein waste. When it fails, toxic plaques build up — damaging memory and cognition.
LRRK2 → Parkinson's
LRRK2 helps brain cells manage waste. Mutations cause toxic buildup in neurons — destroying movement control over time.
