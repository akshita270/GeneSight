# GeneSight

An AI-powered genomic data analysis and visualization toolkit that makes sense of complex single-cell and bulk RNA-seq datasets.

## What it does

- Processes and analyzes genomic/RNA-seq data with Python
- Generates rich HTML visualizations for exploration
- Applies ML techniques to identify patterns in biological data

## Getting Started

```bash
git clone https://github.com/akshita270/GeneSight
cd GeneSight
pip install -r requirements.txt
python main.py
```

## Key Features

- End-to-end genomic data pipeline
- Interactive HTML-based visualizations
- AI-assisted pattern recognition in gene expression data
